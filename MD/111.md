# libxml2 Trace 插桩编译

```bash
export CC=clang CXX=clang++
export CFLAGS="-g -O1 -fno-omit-frame-pointer -fsanitize=address -fpass-plugin=/root/auto_harness/src/runtime_components/trace_fn_instrument/TraceInstrumentationPass.so -include /root/experiment/magma/magma/src/canary.h -DMAGMA_ENABLE_CANARIES"
export CXXFLAGS="-g -O1 -fno-omit-frame-pointer -fsanitize=address -fpass-plugin=/root/auto_harness/src/runtime_components/trace_fn_instrument/TraceInstrumentationPass.so"
export LDFLAGS="-fsanitize=address"
export LIBS="/root/auto_harness/src/runtime_components/trace_fn_instrument/trace_runtime.o -lrt"

./configure --with-http=no --with-python=no --with-lzma=yes --with-threads=no --enable-shared --disable-static --prefix=/root/libxml2/trace_build/

make -j$(nproc)
make install
```

## 常见问题

### `C compiler cannot create executables`

检查 `-fpass-plugin=` 连字符是否遗漏（`-fpassplugin` 是错误拼写）。也确认 `TraceInstrumentationPass.so` 的 LLVM 版本与 `clang --version` 一致：

```bash
ldd /root/auto_harness/src/runtime_components/trace_fn_instrument/TraceInstrumentationPass.so 2>&1 | grep LLVM | head -3
```

若版本不匹配，需用对应 LLVM 版本重新编译该 pass。
